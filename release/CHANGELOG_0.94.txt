World Builder 0.94

Added
- NPCs and creatures can be spawned: the new NPCs tab lists all ~7,250 characters of the game (people, goblins, animals,
  mounts, monsters, bosses) with their in-game name in your interface language, the internal name and the key. Search and
  a category filter narrow the list; SPAWN (or a double-click) puts the character in front of you, "count" places several
  side by side. The list is read from your installed game at runtime, nothing of it ships with the mod.
  The characters are created through the game's own spawn request and then live by the game's rules: they walk, fight,
  flee and despawn like any other. Hostile ones attack. They are therefore not scene objects (no moving, undo or saving in
  projects). After loading a save, walk a few steps before the first spawn.
- HTTP API: POST /api/npc {"key", "x", "y", "z", "type"} spawns a character (see HTTP_API.md).

Changed
- Editor tools from dofo7777: box selection (drag a rectangle over the world), a context menu on right click in the
  world, rotate the selection in steps and align it to an axis, groups act as one unit, exact number entry next to
  sliders (the small ">"), the Scene tools in the docked window. Menu open / close clears stuck mouse buttons and keys.
- Gizmo, selection outlines and the line/circle preview use the renderer's own camera (path from
  CrimsonDesertTelemetry, thanks): no search for camera copies, no "camera copy in flight" setting to tune, and it
  works right after loading a save. The old search stays as a fallback if a game update moves the camera.
- Camera mode (Home, or the button in the editor's header): a free-flying camera while the editor stays open. W/A/S/D,
  E/Space up, Q/Ctrl down, Shift faster, mouse wheel forward; a right-button drag looks around, a right click opens the
  context menu, editor shortcuts keep working. Your character stays where it is, new objects appear in front of the camera,
  and gizmo and outlines follow it. The game treats it as its real camera, so the world stays visible while you turn. Speed
  and mouse sensitivity are in Settings. The world keeps loading around your character, so very distant flights show
  coarser detail.

Fixed
- Interactive objects (doors, ladders, torches, chests ...) are now created directly from the game's own gimmick table:
  no captured template needed, so they appear right after loading a save without walking first, and the invisible
  objects some players saw are gone. The old template method remains as a fallback; it now prefers a template that has
  already worked, uses fresh templates only once they are 2 s old, and a watchdog logs a replay that hangs.
