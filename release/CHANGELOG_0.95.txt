World Builder 0.95

Added (from dofo7777)
- Time & Weather tab (also in the dock): set the time of day, freeze the day/night lighting without pausing the game,
  clear sky, rain, snow, clouds and wind, and restore the game's own values at any time. Every control that cannot find
  its game data after an update switches itself off, the rest keeps working.
- NPC formations: spawn up to 500 NPCs at once in a line, a grid or a circle, up to 500 m away; drag an NPC from the list
  into the world to spawn it at that spot.
- The dock can switch between Browser, Scene, NPCs and Time & Weather.

Changed
- Placement is done with the mouse gizmo only; the numpad / keyboard placement keys are gone. The placement bar at the top
  has Drop, Cancel, To ground, Level and Snap. To look around while placing: open the editor and use the free camera.
- Prefab list, translations and error names live inside cdmodkit.asi; nothing is written to bin64\cdmodkit any more.
- New overlay hookup (DXGI / DLSS / Streamline aware, safer when the game resizes or recreates its swapchain).

Fixed
- Campfires, cooking stations and beds placed with 0.94 could not be used (no cooking, no sleeping). Interactive objects are
  now created exactly like the game creates its own world objects, so every station works right after placing, and still
  without walking first after loading a save.
- If the game ever gets stuck while creating an interactive object, the log now records where, so it can be fixed.
